## Q1. Define Statistics. Explain its Functions, Uses, and Limitations. [5-10 Marks] — 3/5 papers

### a) Core Concept
**Statistics** is the science of **collecting, classifying, presenting, analyzing, and interpreting** quantitative data to assist in making informed decisions under conditions of uncertainty.

### b) Detailed Explanation

**Functions of Statistics:**
1. **Condensation**: Reduces large volumes of raw data into summarized form (tables, averages, charts)
2. **Comparison**: Enables comparison between groups, time periods, or regions using ratios, percentages, and averages
3. **Estimation**: Allows estimation of unknown population parameters from sample data
4. **Forecasting**: Predicts future trends using regression, time-series analysis
5. **Hypothesis Testing**: Validates claims and theories scientifically through tests of significance

**Uses of Statistics:**
| Domain | Application |
|--------|-------------|
| **Business & Trade** | Market research, demand forecasting, inventory control, quality assurance |
| **Economics** | National income estimation, CPI calculation, GDP analysis, inflation tracking |
| **Medicine** | Clinical drug trials, epidemiological studies, survival analysis |
| **Government** | Census operations, budget allocation, policy planning |
| **Engineering** | Reliability testing, process control, Six Sigma quality management |
| **Banking & Finance** | Credit risk scoring, portfolio optimization, fraud detection |
| **Research** | Experimental design, hypothesis validation, data-driven decision making |

**Limitations of Statistics:**
1. **Deals with aggregates only** — Cannot study individual cases; applies to groups
2. **Quantitative data only** — Qualitative attributes (beauty, honesty) require numerical coding
3. **Results are averages** — Average income of ₹50,000 may hide that one person earns ₹5,00,000 and nine earn ₹0
4. **Can be misused** — "There are lies, damned lies, and statistics" — Mark Twain
5. **Not exact laws** — Statistical laws are approximations, not deterministic truths
6. **Requires homogeneous data** — Comparing unlike groups (e.g., GDP of India vs. Luxembourg without per-capita adjustment) is invalid
7. **Does not reveal causation** — Correlation between ice cream sales and drowning does not mean one causes the other

### e) Real-World Example
The Reserve Bank of India (RBI) uses statistical analysis of CPI data, GDP growth rates, and money supply metrics to set the repo rate, directly impacting interest rates across the economy.

## Q2. Justify: "Charts or graphs are more effective in attracting attention than any other method of presenting data." [5 Marks] — Dec 2024

### a) Core Concept
Diagrammatic and graphical representations transform raw numerical data into **visual formats** that are immediately comprehensible, making them superior to tabular or textual presentation for quick understanding and lasting impression.

### b) Detailed Explanation

**Arguments FOR (Justification):**
1. **Immediate visual impact** — A bar chart showing declining sales is grasped in seconds; a table of 100 numbers takes minutes
2. **Facilitates comparison** — Side-by-side bars or overlapping lines instantly reveal differences
3. **Universal comprehension** — No statistical expertise required; even laypersons understand pie charts
4. **Lasting impression** — Visual memory retains images longer than numbers
5. **Identifies patterns & trends** — Line graphs reveal upward/downward trends, seasonality, and outliers at a glance
6. **Attractive presentation** — Enhances reports, business presentations, and publications

**Limitations (Partial Counter-argument):**
- Cannot show **exact values** as precisely as tables
- **Oversimplification** may hide nuances in complex data
- **Misleading** if scales are manipulated (truncated Y-axis, distorted proportions)

**Conclusion:** While not a replacement for detailed tabular analysis, charts and graphs are **more effective for communication, comparison, and quick decision-making**, making the statement largely justified.

## Q4. Define and explain: Grouped Data, Class Interval, Class Limits, Class Boundaries, Class Mark, Inclusive & Exclusive Series, Frequency, Tally Marks. [10 Marks] — Dec 2024

### b) Detailed Explanation with Example

**Raw Data:** 12, 15, 18, 21, 24, 27, 30, 33, 36, 39

| Term | Definition | Example |
|------|-----------|---------|
| **Grouped Data** | Data organized into classes with frequencies | 10-20: 3 students, 20-30: 4 students |
| **Class Interval** | Width/size of each class = Upper − Lower limit | 20 − 10 = **10** |
| **Class Limits** | Lower (L) and Upper (U) values defining a class | In "10-20": L=10, U=20 |
| **Class Boundaries** | True limits for continuous data: L−0.5, U+0.5 | 10-20 → boundaries: **9.5 to 20.5** |
| **Class Mark (Midpoint)** | (Lower + Upper) / 2 | (10+20)/2 = **15** |
| **Inclusive Series** | Both limits are included: 10-19, 20-29 | Value 19 belongs to "10-19" |
| **Exclusive Series** | Upper limit excluded: 10-20, 20-30 | Value 20 belongs to "20-30", NOT "10-20" |
| **Frequency (f)** | Count of observations falling in each class | Class 10-20 has f = 3 |
| **Tally Marks** | Counting system in groups of 5 | \|\|\|\|\ = 5, \|\|\|\|\ \|\| = 7 |

### c) Conversion Diagram
```
Inclusive → Exclusive Conversion:
┌────────────┐        ┌────────────┐
│ 10-19      │  →     │ 9.5-19.5   │
│ 20-29      │  →     │ 19.5-29.5  │
│ 30-39      │  →     │ 29.5-39.5  │
└────────────┘        └────────────┘
Adjustment = 0.5 (half of gap between classes)
```

## Q5. Explain Skewness and its Tests/Measures. [10 Marks]

### a) Core Concept
**Skewness** measures the degree and direction of **asymmetry** in a frequency distribution relative to a symmetric (normal) bell curve.

### c) Diagram
```
Positive Skew:        Symmetric:         Negative Skew:
    ╱╲                  ╱╲                    ╱╲
   ╱  ╲____         __╱  ╲__            ____╱  ╲
  ╱        ╲       ╱        ╲          ╱        ╲
Mo < Md < Mean   Mo = Md = Mean    Mean < Md < Mo
(tail → right)   (no tail)         (tail → left)
```

### d) Formulas

**1. Karl Pearson's Coefficient:**
```
Sk_P = (Mean − Mode) / σ

If Mode is ill-defined: Sk_P = 3(Mean − Median) / σ

Range: approximately −3 to +3
```

**2. Bowley's Coefficient (Quartile-based):**
```
Sk_B = (Q₃ + Q₁ − 2Q₂) / (Q₃ − Q₁)

Range: −1 to +1
```

**3. Moment-based (Fisher's):**
```
γ₁ = μ₃ / (μ₂)^(3/2)

Where μ₂ = second central moment, μ₃ = third central moment
```

| Measure | Formula | Range | Best For |
|---------|---------|-------|----------|
| Pearson | (Mean−Mode)/σ | −3 to +3 | Unimodal distributions |
| Bowley | (Q₃+Q₁−2Q₂)/(Q₃−Q₁) | −1 to +1 | Open-ended distributions |
| Fisher | μ₃/(μ₂)^1.5 | −∞ to +∞ | Theoretical/mathematical analysis |

## Q6. Distinguish between Primary and Secondary Data. What precautions should be taken for Secondary Data? [10 Marks] — 2/5

### a) Core Concept
**Primary data** is collected first-hand by the investigator for a specific purpose. **Secondary data** is data already collected and published by someone else for a different purpose.

### f) Comparison Table

| Parameter | Primary Data | Secondary Data |
|-----------|-------------|----------------|
| **Collected by** | Investigator/Researcher | Government, agencies, other researchers |
| **Originality** | Original, first-hand | Second-hand, pre-existing |
| **Purpose** | Specific to current study | Originally for a different study |
| **Cost** | Expensive (surveys, interviews) | Cheaper (readily available) |
| **Time** | Time-consuming | Quick to obtain |
| **Accuracy** | High (researcher controls quality) | Variable (depends on original collector) |
| **Form** | Raw, unprocessed | Usually processed/summarized |
| **Sources** | Observation, interview, questionnaire, experiment | Census reports, journals, company records, government publications |

### Precautions for Using Secondary Data:
1. **Reliability of source** — Is the collecting agency reputable?
2. **Suitability** — Does the data fit your research objectives?
3. **Adequacy** — Is the sample size and coverage sufficient?
4. **Time period** — Is the data current or outdated?
5. **Units and definitions** — Are the measurement units consistent with your study?
6. **Methodology** — Was the original collection method sound and unbiased?
7. **Degree of accuracy** — What was the margin of error in the original study?

## Q7. What are the various Methods of Collecting Data? Which is more reliable and why? [10 Marks] — 3/5

### b) Methods

**1. Direct Personal Interview:**
- Investigator meets respondent face-to-face
- Most reliable for sensitive/complex topics
- Expensive, limited coverage, interviewer bias possible

**2. Indirect Oral Investigation:**
- Information collected from third parties who know the subject
- Used when direct contact is impossible (e.g., studying criminal behavior)

**3. Mailed Questionnaire:**
- Printed list of questions sent by post/email
- Wide coverage, low cost, but low response rate (typically 20-30%)

**4. Schedule Method:**
- Similar to questionnaire but filled by trained enumerators
- Higher response rate, can include illiterate respondents

**5. Observation Method:**
- Data recorded by watching events/behavior directly
- No respondent bias, but observer bias possible

**6. Experimental Method:**
- Controlled conditions; manipulate variables to observe effects
- Gold standard for causal inference

**Most Reliable:** **Direct Personal Interview** — because the investigator can clarify doubts, verify responses on the spot, ensure completeness, and adapt questions based on context. However, it is the most expensive and time-consuming method.

## Q8. Differentiate between Questionnaire and Schedule. State essential points for drafting a Questionnaire. [10 Marks]

### f) Comparison Table

| Parameter | Questionnaire | Schedule |
|-----------|--------------|----------|
| **Filled by** | Respondent | Trained enumerator |
| **Cost** | Low (can be mailed) | High (need field workers) |
| **Response rate** | Low (30-40%) | High (80-90%) |
| **Literacy requirement** | Respondent must be literate | Can cover illiterate populations |
| **Coverage** | Wide geographical area | Limited area |
| **Interviewer bias** | Absent | Possible |
| **Depth of response** | Superficial | Can probe deeper with follow-ups |
| **Time** | Slow (waiting for returns) | Faster (immediate collection) |
| **Accuracy** | Lower (misunderstood questions) | Higher (enumerator explains) |

### Essential Points for Drafting a Questionnaire:
1. **Simple, clear language** — Avoid jargon; use terms the respondent understands
2. **Logical sequence** — Start with easy/general questions, move to specific/sensitive ones
3. **Short and focused** — Avoid respondent fatigue; limit to essential questions only
4. **Avoid leading questions** — "Don't you agree that X is bad?" is biased
5. **Mix question types** — Include both closed (MCQ, Yes/No) and open-ended questions
6. **Pre-test (pilot study)** — Test on a small group before full deployment
7. **Ensure anonymity** — Especially for sensitive topics, to encourage honest responses
8. **Clear instructions** — Provide guidance on how to answer each section

## Q9. Explain Sampling — its purpose and types. Differentiate Probability and Non-Probability Sampling. [10 Marks] — 2/5

### a) Core Concept
**Sampling** is the process of selecting a representative subset (sample) from a larger population to draw inferences about the entire population without examining every unit.

### b) Purpose
1. Reduces **cost and time** compared to complete enumeration
2. Greater **accuracy** — focused effort on fewer units allows better quality control
3. Essential when population is **infinite** or testing is **destructive** (e.g., testing bulb lifespan)
4. Provides basis for **statistical inference** — confidence intervals, hypothesis tests

### f) Comparison: Probability vs Non-Probability Sampling

| Parameter | Probability Sampling | Non-Probability Sampling |
|-----------|---------------------|-------------------------|
| **Selection basis** | Random — each unit has a known, non-zero probability | Subjective judgment or convenience |
| **Bias** | Minimal — selection is objective | Higher — researcher's judgment involved |
| **Generalizability** | Results generalizable to population | Limited generalizability |
| **Statistical inference** | Valid confidence intervals and hypothesis tests | Cannot compute sampling error |
| **Cost** | Higher (requires sampling frame) | Lower |
| **Types** | Simple Random, Stratified, Systematic, Cluster | Convenience, Judgment, Quota, Snowball |
| **Used when** | Precision and representativeness required | Exploratory research, quick surveys |

### Stratified Sampling:
- Population divided into **homogeneous strata** (e.g., by age group, income level)
- Random sample drawn from **each stratum** proportionally
- **Merits:** More representative, lower sampling error, allows sub-group analysis
- **Limitations:** Requires prior knowledge of strata, complex to design

### Census Method:
- Complete enumeration of every unit in the population
- **Merits:** No sampling error, comprehensive data for all units
- **Demerits:** Expensive, time-consuming, impractical for large/infinite populations

## Q10. Explain Random Variable and its Mathematical Expectation. [10 Marks]

### a) Core Concept
A **random variable** is a function that assigns a numerical value to each outcome of a random experiment. **Mathematical expectation** is the theoretical long-run average value of the random variable.

### b) Types
- **Discrete:** Countable values (e.g., number of defective items: 0, 1, 2, ...)
- **Continuous:** Any value in an interval (e.g., height: 165.3 cm, 170.8 cm, ...)

### d) Formulas
```
Discrete:   E(X) = ∑ xᵢ · P(xᵢ)
Continuous: E(X) = ∫ x · f(x) dx

Variance:   Var(X) = E(X²) − [E(X)]²

Properties:
1. E(c) = c                    (constant)
2. E(cX) = c · E(X)            (scalar multiplication)
3. E(X + Y) = E(X) + E(Y)      (linearity)
4. E(XY) = E(X)·E(Y)           (only if X,Y independent)
5. Var(cX) = c² · Var(X)
```

### e) Example
Insurance company: Premium = ₹500/year. P(claim of ₹50,000) = 0.005.
Expected payout = 50000 × 0.005 = ₹250. Expected profit per policy = 500 − 250 = **₹250**.

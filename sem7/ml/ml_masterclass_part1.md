## Q1. Simple Linear Regression: Theory, OLS Derivations, Best-Fit Terminology, Evaluation Metrics & Solved Numericals [10 Marks]
*(Appeared in: Dec 2022 Q1b [5M]/Q2b [10M], May 2023 Q1b [5M]/Q2b [10M]/Q6a [10M], Dec 2023 Q3a [10M], May 2024 Q3a [10M], Dec 2024 Q1c [5M], May 2025 Q1b [5M]/Q3b [10M], Nov 2025 Q1b [5M]/Q2b [10M])*

### a) Core Concept & Mathematical Formulation
**Linear Regression** is a supervised parametric learning algorithm that models the linear relationship between a continuous scalar dependent variable $Y$ and one or more independent predictor variables $X$.

For simple univariate linear regression with $N$ observations:
$$y_i = \beta_0 + \beta_1 x_i + \epsilon_i, \quad i = 1, 2, \dots, N$$
Where:
- $y_i$ is the actual continuous ground-truth value.
- $x_i$ is the input predictor feature.
- $\beta_0$ (or $c$) is the $y$-intercept (value of $y$ when $x = 0$).
- $\beta_1$ (or $m, a$) is the regression slope coefficient ($\frac{\Delta y}{\Delta x}$).
- $\epsilon_i$ is the unobserved random error term assumed to be independently and identically distributed with zero mean: $\epsilon_i \sim \mathcal{N}(0, \sigma^2)$.

The predicted value generated by the model hypothesis is:
$$\hat{y}_i = \beta_0 + \beta_1 x_i$$

```
   Y (Dependent Variable)
    ^
    |                                   * (Actual data point: (x_i, y_i))
    |                                  /|
    |                                 / | Residual e_i = y_i - \hat{y}_i
    |                                /  v
    |                     *         /   * (\hat{y}_i = \beta_0 + \beta_1 x_i)
    |                      \       /
    |                       \     /   Regression Line
    |                        v   /
    |                         * /
    |                          /
    |             *           /
    |            /           /
    |           v           /
    |            *         /
    |                     /
    |   *                /
    |  /                /
    | v                /
    |  *              /
    |                /
    +---------------+----------------------------------------> X (Independent Variable)
    0               Intercept (\beta_0)
```

### b) Ordinary Least Squares (OLS) Closed-Form Derivations
Ordinary Least Squares finds the optimal parameters $\beta_0, \beta_1$ that minimize the **Sum of Squared Errors (SSE)**:

$$\mathrm{SSE}(\beta_0, \beta_1) = \sum_{i=1}^N e_i^2 = \sum_{i=1}^N (y_i - \hat{y}_i)^2 = \sum_{i=1}^N (y_i - (\beta_0 + \beta_1 x_i))^2$$

#### Step 1: Partial Derivative with respect to $\beta_0$ (Intercept)
$$\frac{\partial \mathrm{SSE}}{\partial \beta_0} = -2 \sum_{i=1}^N (y_i - \beta_0 - \beta_1 x_i) = 0$$
$$\sum_{i=1}^N y_i - N\beta_0 - \beta_1 \sum_{i=1}^N x_i = 0 \implies N\bar{y} - N\beta_0 - N\beta_1 \bar{x} = 0$$
Dividing by $N$:
$$\mathbf{\beta_0 = \bar{y} - \beta_1 \bar{x}}$$

#### Step 2: Partial Derivative with respect to $\beta_1$ (Slope)
$$\frac{\partial \mathrm{SSE}}{\partial \beta_1} = -2 \sum_{i=1}^N x_i (y_i - \beta_0 - \beta_1 x_i) = 0$$
$$\sum_{i=1}^N x_i y_i - \beta_0 \sum_{i=1}^N x_i - \beta_1 \sum_{i=1}^N x_i^2 = 0$$
Substituting $\beta_0 = \bar{y} - \beta_1 \bar{x}$:
$$\sum_{i=1}^N x_i y_i - (\bar{y} - \beta_1 \bar{x}) \sum_{i=1}^N x_i - \beta_1 \sum_{i=1}^N x_i^2 = 0$$
$$\sum_{i=1}^N x_i y_i - \bar{y}\sum_{i=1}^N x_i + \beta_1 \bar{x} \sum_{i=1}^N x_i - \beta_1 \sum_{i=1}^N x_i^2 = 0$$
$$\sum_{i=1}^N x_i y_i - N\bar{x}\bar{y} = \beta_1 \left( \sum_{i=1}^N x_i^2 - N\bar{x}^2 \right)$$
$$\mathbf{\beta_1 = \frac{\sum_{i=1}^N (x_i - \bar{x})(y_i - \bar{y})}{\sum_{i=1}^N (x_i - \bar{x})^2} = \frac{N \sum x_i y_i - (\sum x_i)(\sum y_i)}{N \sum x_i^2 - (\sum x_i)^2}}$$

#### Multivariate Matrix Normal Equation:
For multiple features $X \in \mathbb{R}^{N \times (D+1)}$ and targets $Y \in \mathbb{R}^{N \times 1}$:
$$\mathbf{\theta = (X^T X)^{-1} X^T Y}$$

### c) Core Terminology in Linear Regression Analysis
*(Explicitly tested in Nov 2025 Q1b [5 Marks])*

1. **Scatter Plot:** A two-dimensional Cartesian graph plotting individual observed paired samples $(x_i, y_i)$ as discrete points. It provides an immediate visual diagnostic of data distribution, linear vs non-linear trends, homoscedasticity, clustering, and outlier anomalies.
2. **Regression Line:** The geometric mathematical locus $\hat{y} = \beta_0 + \beta_1 x$ passing through the data swarm. It embodies the conditional expectation function $\mathbb{E}[Y \mid X = x]$ and always passes through the centroid point of the sample distributions $(\bar{x}, \bar{y})$.
3. **Residual ($e_i$):** The signed vertical distance between an empirical observed ground-truth value $y_i$ and the estimated model prediction $\hat{y}_i$:
   $$e_i = y_i - \hat{y}_i$$
   Under Gauss-Markov assumptions, residuals must possess zero mean ($\sum e_i = 0$), constant variance (homoscedasticity), and zero serial autocorrelation.
4. **Best Fitting Line:** The unique line among an infinite family of possible linear trajectories that **minimizes the Sum of Squared Residuals (SSE)**. It represents the global minimum of the quadratic convex loss surface.

---

### d) Regression Performance Evaluation Measures
To quantify model accuracy and residual dispersion, four standard diagnostic metrics are employed:

1. **Mean Absolute Error (MAE):**
   $$\mathrm{MAE} = \frac{1}{N} \sum_{i=1}^N |y_i - \hat{y}_i|$$
   Measures average absolute error magnitude in native units; robust to extreme outliers.
2. **Mean Squared Error (MSE):**
   $$\mathrm{MSE} = \frac{1}{N} \sum_{i=1}^N (y_i - \hat{y}_i)^2$$
   Penalizes large errors quadratically; foundational for optimization.
3. **Root Mean Squared Error (RMSE):**
   $$\mathrm{RMSE} = \sqrt{\frac{1}{N} \sum_{i=1}^N (y_i - \hat{y}_i)^2}$$
   Brings quadratic penalty back to original target units for intuitive physical interpretation.
4. **Coefficient of Determination ($\mathrm{R}^2$ Score):**
   $$\mathrm{R}^2 = 1 - \frac{\mathrm{SS}_{\mathrm{res}}}{\mathrm{SS}_{\mathrm{tot}}} = 1 - \frac{\sum_{i=1}^N (y_i - \hat{y}_i)^2}{\sum_{i=1}^N (y_i - \bar{y})^2}$$
   - Quantifies the proportion of total target variance explained by the predictor: $0 \le \mathrm{R}^2 \le 1$.
   - $\mathrm{R}^2 = 1 \implies$ Perfect fit (zero error).
   - $\mathrm{R}^2 = 0 \implies$ Model performs no better than simply predicting the mean $\bar{y}$.

### e) Solved Numerical 1 (Nov 2025): Month vs Organization Expenditure
*(Appeared in: November 2025 Paper, Question 2(b) [10 Marks])*

Explain simple linear regression. Find regression line $Y = aX + C$ using least squares method and estimate the expenditure of company in $6^{\text{th}}$ month using the line as a model.
Expenditure data (in thousand) is given below:

| Month ($X$) | 1 | 2 | 3 | 4 | 5 |
| :--- | :---: | :---: | :---: | :---: | :---: |
| Expenditure ($Y$) | 12 | 19 | 29 | 37 | 45 |

#### Step 1: Tabular Computation of Sums ($N = 5$)

| Month ($X$) | Expenditure ($Y$) | $X^2$ | $X \cdot Y$ | $Y^2$ |
| :---: | :---: | :---: | :---: | :---: |
| 1 | 12 | 1 | 12 | 144 |
| 2 | 19 | 4 | 38 | 361 |
| 3 | 29 | 9 | 87 | 841 |
| 4 | 37 | 16 | 148 | 1369 |
| 5 | 45 | 25 | 225 | 2025 |
| **$\sum X = 15$** | **$\sum Y = 142$** | **$\sum X^2 = 55$** | **$\sum XY = 510$** | **$\sum Y^2 = 4740$** |

#### Step 2: Sample Means
$$\bar{X} = \frac{\sum X}{N} = \frac{15}{5} = \mathbf{3.0}$$
$$\bar{Y} = \frac{\sum Y}{N} = \frac{142}{5} = \mathbf{28.4}$$

#### Step 3: Compute Slope ($a$)
$$a = \frac{N \sum XY - (\sum X)(\sum Y)}{N \sum X^2 - (\sum X)^2} = \frac{5(510) - (15)(142)}{5(55) - (15)^2} = \frac{2550 - 2130}{275 - 225} = \frac{420}{50} = \mathbf{8.4}$$

#### Step 4: Compute Intercept ($C$)
$$C = \bar{Y} - a\bar{X} = 28.4 - 8.4(3.0) = 28.4 - 25.2 = \mathbf{3.2}$$

#### Step 5: Final Regression Model & Prediction
$$\mathbf{Y = 8.4 X + 3.2}$$
For Month $X = 6$:
$$Y(6) = 8.4(6) + 3.2 = 50.4 + 3.2 = \mathbf{53.60 \text{ thousand}} \quad (\mathbf{₹53,600})$$

## Q2. Decision Trees: Foundations, Impurity Measures, ID3 & CART Algorithms, Pruning & Solved Numericals [10 Marks]
*(Appeared in: Dec 2022 Q3a [10M], May 2023 Q3a [10M], Dec 2023 Q4b [10M], May 2024 Q4b [10M], Dec 2024 Q4b [10M], May 2025 Q3a [10M], Nov 2025 Q1e [5M])*

### a) Anatomy & Architectural Workflow of a Decision Tree
A **Decision Tree** is a non-parametric supervised learning model that recursively partitions the input feature space into homogeneous hyper-rectangles using hierarchical axis-aligned decision rules.

```
+---------------------------------------------------------------------------------------------------+
|                                   DECISION TREE ARCHITECTURE                                      |
+---------------------------------------------------------------------------------------------------+
|                                      [ ROOT NODE ]                                                |
|                             Attribute with Max Info Gain / Min Gini                               |
|                                       /            \                                              |
|                           Condition <= t          Condition > t                                   |
|                                     /                \                                            |
|                                    v                  v                                           |
|                           [ INTERNAL NODE ]      [ LEAF NODE ]                                    |
|                           Split on Attribute B    Class Label C1                                  |
|                                /        \                                                         |
|                               v          v                                                        |
|                         [ LEAF NODE ]  [ LEAF NODE ]                                              |
|                         Class Label C2 Class Label C1                                             |
+---------------------------------------------------------------------------------------------------+
```

---

### b) Splitting Criteria: Entropy vs Information Gain vs Gini Index
To select the optimal attribute at each node, mathematical impurity metrics quantify the degree of disorder:

#### 1. Entropy (Used in ID3 & C4.5):
Measures the expected information content (in bits) of dataset $D$ with $C$ classes:
$$H(D) = -\sum_{i=1}^C p_i \log_2(p_i)$$
Where $p_i$ is the empirical probability of class $i$.
- If a node is pure ($p_1 = 1, p_2 = 0$): $H(D) = -(1 \log_2 1 + 0) = \mathbf{0 \text{ bits}}$.
- If maximally impure ($p_1 = 0.5, p_2 = 0.5$): $H(D) = -(0.5 \log_2 0.5 + 0.5 \log_2 0.5) = \mathbf{1.0 \text{ bit}}$.

#### 2. Information Gain (ID3):
The expected reduction in entropy achieved by partitioning dataset $D$ on attribute $A$:
$$\mathrm{Gain}(D, A) = H(D) - \sum_{v \in \mathrm{Values}(A)} \frac{|D_v|}{|D|} H(D_v)$$
*ID3 selects the attribute that maximizes $\mathrm{Gain}(D, A)$.*

#### 3. Gini Impurity (Used in CART):
Measures the probability of misclassifying a randomly chosen element from the set:
$$\mathrm{Gini}(D) = 1 - \sum_{i=1}^C p_i^2$$
- Pure node ($p_1 = 1, p_2 = 0$): $\mathrm{Gini}(D) = 1 - (1^2 + 0^2) = \mathbf{0.0}$.
- Maximally impure node ($p_1 = 0.5, p_2 = 0.5$): $\mathrm{Gini}(D) = 1 - (0.5^2 + 0.5^2) = \mathbf{0.50}$.

For attribute $A$ splitting $D$ into subsets $\{D_v\}$:
$$\mathrm{Gini}_{\mathrm{split}}(D, A) = \sum_{v \in \mathrm{Values}(A)} \frac{|D_v|}{|D|} \mathrm{Gini}(D_v)$$
$$\mathrm{GiniGain}(D, A) = \mathrm{Gini}(D) - \mathrm{Gini}_{\mathrm{split}}(D, A)$$
*CART selects the attribute that minimizes $\mathrm{Gini}_{\mathrm{split}}(D, A)$ (or maximizes Gini Gain).*

---

### c) Overfitting & Tree Pruning Strategies
Unconstrained decision trees grow until every leaf is pure, creating complex boundaries that memorize noise (low bias, extreme variance).

1. **Pre-Pruning (Early Stopping):** Halts tree growth before full expansion if:
   - Node depth exceeds `max_depth`.
   - Sample count falls below `min_samples_split`.
   - Impurity reduction is less than a threshold $\Delta \mathrm{Gini} < \theta$.
2. **Post-Pruning (Cost-Complexity Pruning):** Grows the tree to maximum depth, then removes non-significant subtrees by minimizing the cost-complexity objective:
   $$R_\alpha(T) = R(T) + \alpha |T|$$
   Where $R(T)$ is misclassification error, $|T|$ is number of terminal leaves, and $\alpha$ is complexity penalty tuned via cross-validation.

## Q3. Classification Performance Evaluation: Confusion Matrix & Diagnostic Metrics [5–10 Marks]
*(Appeared in: Dec 2022 Q6a [10M], Dec 2023 Q1c/e [10M], May 2024 Q1c [5M], Dec 2024 Q1e [5M]/Q2b [10M], May 2025 Q1d [5M]/Q6a [10M], Nov 2025 Q1d [5M])*

### a) The $2 \times 2$ Confusion Matrix Layout
In binary classification, model performance is evaluated by contrasting actual ground-truth labels against model predictions:

```
+---------------------------------------------------------------------------------------------------+
|                                  THE 2x2 CONFUSION MATRIX ARCHITECTURE                            |
+---------------------------------------------------------------------------------------------------+
|                              |                    PREDICTED CLASS                                 |
|                              |----------------------------------+---------------------------------|
|                              | PREDICTED POSITIVE (1)           | PREDICTED NEGATIVE (0)          |
+------------------------------+----------------------------------+---------------------------------+
| ACTUAL POSITIVE (1)          | True Positive (TP)               | False Negative (FN)             |
|                              | (Correctly identified positive)  | (Type II Error / Missed)        |
+------------------------------+----------------------------------+---------------------------------+
| ACTUAL NEGATIVE (0)          | False Positive (FP)              | True Negative (TN)              |
|                              | (Type I Error / False Alarm)     | (Correctly rejected negative)   |
+------------------------------+----------------------------------+---------------------------------+
```

---

### b) Primary Diagnostic Metrics & Mathematical Formulations
All multi-metric evaluations derive directly from the four fundamental cells:

1. **Classification Accuracy:** Proportion of total predictions that were correct:
   $$\mathrm{Accuracy} = \frac{\mathrm{TP} + \mathrm{TN}}{\mathrm{TP} + \mathrm{TN} + \mathrm{FP} + \mathrm{FN}}$$
   *Limitation:* Misleading in class-imbalanced datasets (e.g., $99\%$ negative base rate).
2. **Precision (Positive Predictive Value):** Exactness of positive predictions:
   $$\mathrm{Precision} = \frac{\mathrm{TP}}{\mathrm{TP} + \mathrm{FP}}$$
   *Crucial when False Positives carry severe costs (e.g., spam filter blocking vital business emails).*
3. **Recall (Sensitivity / True Positive Rate - TPR):** Completeness of positive identification:
   $$\mathrm{Recall} = \frac{\mathrm{TP}}{\mathrm{TP} + \mathrm{FN}}$$
   *Crucial when False Negatives carry catastrophic costs (e.g., failing to detect malignant tumors).*
4. **Specificity (True Negative Rate - TNR):** Proportion of actual negatives correctly identified:
   $$\mathrm{Specificity} = \frac{\mathrm{TN}}{\mathrm{TN} + \mathrm{FP}}$$
5. **False Positive Rate (FPR):**
   $$\mathrm{FPR} = \frac{\mathrm{FP}}{\mathrm{FP} + \mathrm{TN}} = 1 - \mathrm{Specificity}$$
6. **$\mathrm{F}_1$-Score:** The harmonic mean of Precision and Recall:
   $$\mathrm{F}_1 = 2 \cdot \frac{\mathrm{Precision} \cdot \mathrm{Recall}}{\mathrm{Precision} + \mathrm{Recall}} = \frac{2\mathrm{TP}}{2\mathrm{TP} + \mathrm{FP} + \mathrm{FN}}$$
   *Harmonic mean severely penalizes extreme disparities between Precision and Recall.*

### c) Solved Numerical (Nov 2025): 50 Grant Proposals Evaluation
*(Appeared in: November 2025 Paper, Question 1(d) [Paper Code 42171, 5 Marks])*

#### Problem Statement:
Find the Confusion Matrix, Calculate Accuracy, Precision, Recall, and F1-Score for the following grant proposal classification problem:
Total proposals = 50. Actual positive: 25, Actual negative: 25.

| | Predicted: Yes | Predicted: No | Total |
| :--- | :---: | :---: | :---: |
| **Actual: Yes** | 20 | 5 | 25 |
| **Actual: No** | 10 | 15 | 25 |
| **Total** | 30 | 20 | 50 |

#### Step 1: Cell Identification
- $\mathrm{TP} = 20$ (Actual Yes, Predicted Yes)
- $\mathrm{FN} = 5$ (Actual Yes, Predicted No)
- $\mathrm{FP} = 10$ (Actual No, Predicted Yes)
- $\mathrm{TN} = 15$ (Actual No, Predicted No)
- Total samples $N = 20 + 5 + 10 + 15 = 50$.

#### Step 2: Calculate Accuracy
$$\mathrm{Accuracy} = \frac{\mathrm{TP} + \mathrm{TN}}{N} = \frac{20 + 15}{50} = \frac{35}{50} = \mathbf{0.7000} \quad (\mathbf{70.00\%})$$

#### Step 3: Calculate Precision
$$\mathrm{Precision} = \frac{\mathrm{TP}}{\mathrm{TP} + \mathrm{FP}} = \frac{20}{20 + 10} = \frac{20}{30} = \mathbf{0.6667} \quad (\mathbf{66.67\%})$$

#### Step 4: Calculate Recall (Sensitivity)
$$\mathrm{Recall} = \frac{\mathrm{TP}}{\mathrm{TP} + \mathrm{FN}} = \frac{20}{20 + 5} = \frac{20}{25} = \mathbf{0.8000} \quad (\mathbf{80.00\%})$$

$$\mathrm{F}_1 = 2 \cdot \frac{\mathrm{Precision} \cdot \mathrm{Recall}}{\mathrm{Precision} + \mathrm{Recall}} = 2 \cdot \frac{\left(\frac{2}{3}\right) \cdot \left(\frac{4}{5}\right)}{\frac{2}{3} + \frac{4}{5}} = 2 \cdot \frac{\frac{8}{15}}{\frac{22}{15}} = 2 \cdot \frac{8}{22} = \frac{16}{22} = \mathbf{0.7273} \quad (\mathbf{72.73\%})$$

- **Type II Error ($\beta$, False Negative):** Failing to reject a false null hypothesis. In airport weapon detection or cancer diagnosis, missing a real threat is fatal.

## Q4. Support Vector Machines (SVM): Hyperplanes, Margin Maximization, Duality & The Kernel Trick [10 Marks]
*(Appeared in: Dec 2022 Q1c [5M], Dec 2023 Q1d [5M]/Q4a [10M]/Q5a [10M], May 2024 Q6a [10M], Dec 2024 Q6b [10M]/Q6c [10M], May 2025 Q1c [5M], Nov 2025 Q1c [5M]/Q3a [10M])*

### a) The Optimal Separating Hyperplane & Support Vectors
*(Explicitly tested in Nov 2025 Q1c [5 Marks])*

A linear classifier partitions two linearly separable classes using a hyperplane:
$$\mathbf{w}^T \mathbf{x} + b = 0$$
Where $\mathbf{w}$ is the normal weight vector and $b$ is the scalar bias offset.

```
                  x_2 ^
                      |            + (Class +1)
                      |         +       +
                      |            +   [SV1]  <-- Support Vector
                      |----------------------- w^T x + b = +1 (Positive Margin Boundary)
                      |              /       
                      |             /  Margin \gamma = 2 / ||w||
                      |            /         
                      |======================= w^T x + b = 0  (OPTIMAL SEPARATING HYPERPLANE)
                      |          /           
                      |         /            
                      |----------------------- w^T x + b = -1 (Negative Margin Boundary)
                      |      [SV2]   o
                      |        o        o  (Class -1)
                      |           o
                      +-------------------------------------> x_1
```

#### Why is the Maximum Margin Hyperplane "Optimal"?
1. **Structural Risk Minimization (Vapnik-Chervonenkis Theory):** Rather than merely minimizing empirical training error, maximizing margin width $\gamma = \frac{2}{\|\mathbf{w}\|}$ minimizes the VC-dimension of the hypothesis space, guaranteeing the tightest theoretical upper bound on generalization error.
2. **Support Vectors are the Sole Determinants:** The optimal hyperplane depends strictly on the critical boundary samples lying directly on the margin hyperplanes ($y_i(\mathbf{w}^T \mathbf{x}_i + b) = 1$). All non-support training points can be removed or perturbed without changing the decision boundary.

---

### b) Hard-Margin Primal Formulation
To maximize geometric margin $\frac{2}{\|\mathbf{w}\|}$, we invert and formulate an equivalent convex quadratic programming problem:
$$\min_{\mathbf{w}, b} \frac{1}{2} \|\mathbf{w}\|^2 \quad \text{subject to } y_i (\mathbf{w}^T \mathbf{x}_i + b) \ge 1, \quad \forall i = 1, \dots, N$$

---

### c) Soft-Margin SVM & Slack Variables ($\xi_i$)
For non-linearly separable or noisy distributions, slack variables $\xi_i \ge 0$ allow bounded margin violations:
$$\min_{\mathbf{w}, b, \mathbf{\xi}} \frac{1}{2} \|\mathbf{w}\|^2 + C \sum_{i=1}^N \xi_i \quad \text{subject to } y_i (\mathbf{w}^T \mathbf{x}_i + b) \ge 1 - \xi_i, \quad \xi_i \ge 0$$
Where $C > 0$ is the regularization trade-off parameter:
- **Large $C$:** Heavy penalty for violations $\implies$ narrow margin, higher risk of overfitting.
- **Small $C$:** Tolerates misclassifications $\implies$ wider margin, higher bias, more robust to noise.

---

### d) Lagrangian Dual Optimization & KKT Conditions
Introducing Lagrange multipliers $\alpha_i \ge 0$, the primal objective translates into the Wolfe Dual:
$$\max_{\mathbf{\alpha}} \sum_{i=1}^N \alpha_i - \frac{1}{2} \sum_{i=1}^N \sum_{j=1}^N \alpha_i \alpha_j y_i y_j (\mathbf{x}_i^T \mathbf{x}_j)$$
$$\text{subject to } \sum_{i=1}^N \alpha_i y_i = 0, \quad 0 \le \alpha_i \le C, \quad \forall i$$
The optimal weight vector is recovered as:
$$\mathbf{w}^* = \sum_{i=1}^N \alpha_i y_i \mathbf{x}_i$$
Classification of an unseen test point $\mathbf{x}$ requires only inner products with support vectors:
$$f(\mathbf{x}) = \mathrm{sign}\left( \sum_{i \in \mathrm{SV}} \alpha_i y_i (\mathbf{x}_i^T \mathbf{x}) + b \right)$$

---

### e) The Kernel Trick & Mercer's Theorem
When data is non-linearly separable in input space $\mathbb{R}^d$, it is mapped via a non-linear mapping $\Phi(\mathbf{x})$ into a higher-dimensional Hilbert space $\mathcal{H}$ where it becomes linearly separable.
By **Mercer's Theorem**, any continuous symmetric positive semi-definite kernel function $K(\mathbf{x}_i, \mathbf{x}_j)$ computes the inner product directly without explicitly evaluating $\Phi$:
$$K(\mathbf{x}_i, \mathbf{x}_j) = \langle \Phi(\mathbf{x}_i), \Phi(\mathbf{x}_j) \rangle$$

| Kernel Name | Mathematical Formula | Key Characteristics & Best Used For |
| :--- | :--- | :--- |
| **Linear Kernel** | $K(\mathbf{x}_i, \mathbf{x}_j) = \mathbf{x}_i^T \mathbf{x}_j + c$ | Large feature spaces (e.g., text classification, TF-IDF). |
| **Polynomial Kernel** | $K(\mathbf{x}_i, \mathbf{x}_j) = (\mathbf{x}_i^T \mathbf{x}_j + c)^d$ | Models feature interactions up to degree $d$. |
| **Radial Basis Function (RBF / Gaussian)** | $K(\mathbf{x}_i, \mathbf{x}_j) = \exp(-\gamma \|\mathbf{x}_i - \mathbf{x}_j\|^2)$ | Maps into infinite-dimensional space; general non-linear default. |
| **Sigmoid (Hyperbolic Tangent)** | $K(\mathbf{x}_i, \mathbf{x}_j) = \tanh(\kappa \mathbf{x}_i^T \mathbf{x}_j + c)$ | Emulates multi-layer neural network perceptrons. |

---

### f) Worked Example: Polynomial Kernel Projection ($\mathbb{R}^2 \to \mathbb{R}^3$)
*(Explicitly tested in Nov 2025 Q3a [10 Marks])*

Consider two-dimensional inputs $\mathbf{x} = [x_1, x_2]^T$ and $\mathbf{z} = [z_1, z_2]^T$.
Evaluate the homogeneous quadratic polynomial kernel $K(\mathbf{x}, \mathbf{z}) = (\mathbf{x}^T \mathbf{z})^2$:
$$K(\mathbf{x}, \mathbf{z}) = (x_1 z_1 + x_2 z_2)^2 = x_1^2 z_1^2 + 2 x_1 z_1 x_2 z_2 + x_2^2 z_2^2$$
We can express this scalar product as an inner product $\langle \Phi(\mathbf{x}), \Phi(\mathbf{z}) \rangle$:
$$\Phi(\mathbf{x}) = \begin{bmatrix} x_1^2 \\ \sqrt{2} x_1 x_2 \\ x_2^2 \end{bmatrix}, \quad \Phi(\mathbf{z}) = \begin{bmatrix} z_1^2 \\ \sqrt{2} z_1 z_2 \\ z_2^2 \end{bmatrix}$$
$$\langle \Phi(\mathbf{x}), \Phi(\mathbf{z}) \rangle = (x_1^2)(z_1^2) + (\sqrt{2}x_1 x_2)(\sqrt{2}z_1 z_2) + (x_2^2)(z_2^2) = x_1^2 z_1^2 + 2x_1 x_2 z_1 z_2 + x_2^2 z_2^2 = K(\mathbf{x}, \mathbf{z})$$
**Significance:** Concentric circular patterns in $\mathbb{R}^2$ ($x_1^2 + x_2^2 = r^2$) are impossible to separate with a straight line, but map into a linear plane in $\mathbb{R}^3$, enabling perfect linear separation with zero explicit coordinate transformation overhead.

## Q5. Ensemble Learning Paradigms: Bagging vs Boosting vs Stacking, Random Forest, AdaBoost & XGBoost [10 Marks]
*(Appeared in: Dec 2022 Q4a/b [10M], May 2023 Q4a/b [10M], Dec 2023 Q5b [10M], May 2024 Q2b/Q6b [10M], Dec 2024 Q4a [10M], May 2025 Q4a/b [10M], Nov 2025 Q4a/Q6a [10M])*

### a) Architectural Taxonomy of Ensemble Learning

```
+---------------------------------------------------------------------------------------------------+
|                                 THE 3 ENSEMBLE LEARNING ARCHITECTURES                             |
+---------------------------------------------------------------------------------------------------+
| 1. BAGGING (Bootstrap Aggregation)                                                                |
|    - Trains independent base models in PARALLEL on bootstrap resampled datasets.                 |
|    - Aggregation via Majority Voting (Classification) or Simple Averaging (Regression).           |
|    - Primary Goal: VARIANCE REDUCTION (Prevents overfitting). Base model: High-variance trees.    |
|    - Archetype: RANDOM FOREST.                                                                    |
+---------------------------------------------------------------------------------------------------+
                                                  |
| 2. BOOSTING (Sequential Adaptive Learning)                                                        |
|    - Trains base models SEQUENTIALLY in stages.                                                   |
|    - Each subsequent model focuses heavily on instances misclassified by preceding learners.     |
|    - Primary Goal: BIAS REDUCTION (Converts weak learners into strong learners).                  |
|    - Archetypes: ADABOOST, GRADIENT BOOSTING, XGBOOST.                                            |
+---------------------------------------------------------------------------------------------------+
                                                  |
| 3. STACKING (Stacked Generalization)                                                              |
|    - Trains HETEROGENEOUS base models (e.g., SVM + Random Forest + KNN) in parallel.              |
|    - Predictions feed as input features into a meta-model (e.g., Logistic Regression).           |
|    - Primary Goal: Combining diverse model inductive biases for maximum predictive power.         |
+---------------------------------------------------------------------------------------------------+
```

---

### b) Random Forest Classifier: Subspace Sampling & OOB Error
Random Forest extends Bagging by introducing **Random Feature Subspace Sampling**:
1. **Bootstrap Resampling:** For $B$ trees, draw random sample $D_b$ of size $N$ with replacement from $D$. Approximately $63.2\%$ of samples are selected; $36.8\%$ remain unselected as **Out-of-Bag (OOB)** samples.
2. **Random Subspace Method:** At each candidate split node in each tree, select a random subset of $m$ features out of total $M$ features:
   $$m = \lfloor \sqrt{M} \rfloor \quad (\text{Classification}), \quad m = \lfloor M/3 \rfloor \quad (\text{Regression})$$
3. **De-correlation Effect:** If a dominant feature exists, all standard bagged trees would split on it first, making predictions highly correlated. Random subspace forcing de-correlates the trees, drastically shrinking ensemble variance:
   $$\mathrm{Var}(\bar{X}) = \rho \sigma^2 + \frac{1 - \rho}{B} \sigma^2$$
   As correlation $\rho \to 0$ and $B \to \infty$, ensemble variance collapses toward zero.
4. **Out-of-Bag (OOB) Evaluation:** Each sample is evaluated using only trees where it was omitted during training, providing an unbiased validation metric without requiring a separate validation split.

---

### c) AdaBoost (Adaptive Boosting) Algorithm
Iteratively trains base learners $h_t(\mathbf{x})$ on weighted instances:
1. Initialize instance weights uniformly: $w_i^{(1)} = \frac{1}{N}$.
2. For iteration $t = 1, \dots, T$:
   - Train weak learner $h_t$ minimizing weighted training error:
     $$\epsilon_t = \sum_{i=1}^N w_i^{(t)} \mathbb{I}(y_i \ne h_t(\mathbf{x}_i))$$
   - Compute learner voting weight:
     $$\alpha_t = \frac{1}{2} \ln\left( \frac{1 - \epsilon_t}{\epsilon_t} \right)$$
   - Update instance weights:
     $$w_i^{(t+1)} = \frac{w_i^{(t)} \exp(-\alpha_t y_i h_t(\mathbf{x}_i))}{Z_t}$$
     *(Misclassified samples are assigned exponentially higher weights).*
3. Final ensemble decision:
   $$H(\mathbf{x}) = \mathrm{sign}\left( \sum_{t=1}^T \alpha_t h_t(\mathbf{x}) \right)$$

---

### d) XGBoost (Extreme Gradient Boosting) Architecture
*(Explicitly tested in Nov 2025 Q6a [10 Marks])*

XGBoost optimizes a second-order Taylor expansion of a regularized objective function:
$$\mathcal{L}^{(t)} = \sum_{i=1}^N \ell(y_i, \hat{y}_i^{(t-1)} + f_t(\mathbf{x}_i)) + \Omega(f_t)$$
Where tree complexity regularization is defined as:
$$\Omega(f_t) = \gamma T + \frac{1}{2} \lambda \sum_{j=1}^T w_j^2$$
Using Taylor expansion with first gradients $g_i = \partial_{\hat{y}^{(t-1)}} \ell$ and second Hessians $h_i = \partial_{\hat{y}^{(t-1)}}^2 \ell$:
$$\mathcal{L}^{(t)} \approx \sum_{j=1}^T \left[ \left(\sum_{i \in I_j} g_i\right) w_j + \frac{1}{2} \left(\sum_{i \in I_j} h_i + \lambda\right) w_j^2 \right] + \gamma T$$
The optimal leaf weights $w_j^*$ and split score gain are computed in closed form:
$$w_j^* = -\frac{\sum_{i \in I_j} g_i}{\sum_{i \in I_j} h_i + \lambda}, \quad \mathrm{Gain} = \frac{1}{2} \left[ \frac{(\sum_{L} g_i)^2}{\sum_{L} h_i + \lambda} + \frac{(\sum_{R} g_i)^2}{\sum_{R} h_i + \lambda} - \frac{(\sum_{I} g_i)^2}{\sum_{I} h_i + \lambda} \right] - \gamma$$

## Q6. Density-Based Clustering: DBSCAN Foundations, Density Reachability vs Connectivity & Noise Handling [10 Marks]
*(Appeared in: Dec 2022 Q6c [10M], May 2023 Q6c [10M], Dec 2023 Q6c [10M], May 2024 Q3b [10M], Dec 2024 Q5b [10M], May 2025 Q6c [10M], Nov 2025 Q5b [10M])*

### a) Core Concept & Density Paradigm
**DBSCAN (Density-Based Spatial Clustering of Applications with Noise)** groups points that are packed closely together in high-density regions while marking isolated points in low-density regions as noise.
Unlike K-Means, DBSCAN:
- Does not require pre-specifying cluster count $K$.
- Discovers clusters of arbitrary non-spherical shapes (e.g., concentric circles, spirals).
- Robustly isolates noise anomalies.

---

### b) Fundamental Parameters
1. **$\epsilon$ (Epsilon):** The maximum Euclidean radius defining the neighborhood surrounding a point $p$:
   $$N_\epsilon(p) = \{ q \in D \mid \mathrm{dist}(p, q) \le \epsilon \}$$
2. **$\mathrm{MinPts}$:** The minimum number of points required within $N_\epsilon(p)$ to designate $p$ as a dense core point.

---

### c) Point Classification Taxonomy

```
+---------------------------------------------------------------------------------------------------+
|                                  DBSCAN POINT CLASSIFICATION                                      |
+---------------------------------------------------------------------------------------------------+
|                                                                                                   |
|                                       * q1                                                        |
|                                     /                                                             |
|                          * q2      /                                                              |
|                            \      v                                                               |
|                             +------------+                                                        |
|                             |   CORE     |                                                        |
|                      * q3 ->|   POINT    |<- * q4                                                 |
|                             |    (P)     |                                                        |
|                             +------------+                                                        |
|                                   |  \                                                            |
|                           \eps    |   \                                                           |
|                                   v    * q5                                                       |
|                            +------------+                                                         |
|                            |   BORDER   |                                                         |
|                            |   POINT(B) |                                                         |
|                            +------------+                                                         |
|                                                                                                   |
|                                                    * NOISE POINT (N)                              |
|                                                                                                   |
+---------------------------------------------------------------------------------------------------+
```

1. **Core Point ($P$):** $|N_\epsilon(P)| \ge \mathrm{MinPts}$ (Surrounded by dense points).
2. **Border Point ($B$):** $|N_\epsilon(B)| < \mathrm{MinPts}$, but $B \in N_\epsilon(P)$ for some core point $P$.
3. **Noise Point ($N$):** Neither a core point nor a border point ($|N_\epsilon(N)| < \mathrm{MinPts}$ and not reachable from any core).

---

### d) Density Metrics & Cluster Definition
1. **Directly Density-Reachable:** Point $q$ is directly density-reachable from $p$ if $q \in N_\epsilon(p)$ and $p$ is a core point.
2. **Density-Reachable:** Point $q$ is density-reachable from $p$ if there exists a chain of core points $p_1, p_2, \dots, p_k$ where $p_1 = p$, $p_k = q$, and each $p_{i+1}$ is directly density-reachable from $p_i$. (Asymmetric).
3. **Density-Connected:** Points $p$ and $q$ are density-connected if there exists an intermediate point $o$ such that both $p$ and $q$ are density-reachable from $o$. (Symmetric relation defining a cluster).

---

### e) Algorithmic Execution Steps
```python
def dbscan(D, eps, min_pts):
    clusters = []
    visited = set()
    for point in D:
        if point in visited:
            continue
        visited.add(point)
        neighbors = get_neighbors(point, eps)
        if len(neighbors) < min_pts:
            point.label = "NOISE"
        else:
            new_cluster = expand_cluster(point, neighbors, eps, min_pts, visited)
            clusters.append(new_cluster)
    return clusters
```

---

### f) Comparative Matrix: K-Means vs DBSCAN

| Parameter | K-Means | DBSCAN |
| :--- | :--- | :--- |
| **Number of Clusters ($K$)** | Must be predefined manually. | Discovered dynamically based on density. |
| **Cluster Geometry** | Restricted strictly to spherical/convex shapes. | Arbitrary non-linear shapes (spirals, rings). |
| **Outlier Robustness** | Sensitive; forces noise points into clusters. | Completely robust; isolates noise points cleanly. |
| **Time Complexity** | $\mathcal{O}(N \cdot K \cdot I)$ (Fast). | $\mathcal{O}(N^2)$ brute-force; $\mathcal{O}(N \log N)$ with $k$-d trees. |
| **Varying Densities** | Handles uniform variance reasonably well. | Fails when clusters have drastically differing densities. |

### c) Core Operational Issues & Challenges in Machine Learning
1. **Data Quality & Bias:** Incomplete features, class imbalance, and human labeling bias leading to biased algorithmic outcomes.

4. **Concept Drift & Covariate Shift:** Statistical divergence between training distribution $P_{\mathrm{train}}(X, Y)$ and real-time inference distributions $P_{\mathrm{test}}(X, Y)$ over time.

### e) End-to-End System Design Case Study: Email Spam Detection System
*(Explicitly tested in Nov 2025 Q4b [10 Marks])*

#### 1. System Architecture
```
+---------------------------------------------------------------------------------------------------+
|                            EMAIL SPAM DETECTION SYSTEM ARCHITECTURE                               |
+---------------------------------------------------------------------------------------------------+
|  [ INCOMING RAW EMAIL ]                                                                           |
|  "Subject: URGENT WINNER! Claim $1,000,000 cash prize instantly at http://scam.ru..."             |
+---------------------------------------------------------------------------------------------------+
                                                  |
                                                  v
|  STAGE 1: TEXT PREPROCESSING PIPELINE                                                             |
|  - HTML Tag Stripping (BeautifulSoup)                                                             |
|  - Lowercasing & Punctuation Removal                                                              |
|  - Tokenization (NLTK TreebankTokenizer)                                                          |
|  - Stopword Removal ("the", "is", "at")                                                           |
|  - Lemmatization (WordNetLemmatizer: "claimed" -> "claim", "prizes" -> "prize")                   |
+---------------------------------------------------------------------------------------------------+
                                                  |
                                                  v
|  STAGE 2: NUMERICAL FEATURE EXTRACTION                                                            |
|  - TF-IDF Vectorization (Top 10,000 unigrams + bigrams)                                           |
|  - Heuristic Engineering: Caps-lock ratio, Exclamation mark density, Phishing URL count.          |
+---------------------------------------------------------------------------------------------------+
                                                  |
                                                  v
|  STAGE 3: CLASSIFIER INFERENCE & BENCHMARKING                                                     |
|  - Baseline: Multinomial Naive Bayes (Fast, log-odds scoring)                                     |
|  - Production Model: Linear Support Vector Machine (LinearSVC with calibrated probabilities)      |
+---------------------------------------------------------------------------------------------------+
                                                  |
                                                  v
|  STAGE 4: DECISION & ACTION ROUTING                                                               |
|  - Spam Score >= 0.85: Silently route to SPAM JUNK FOLDER.                                         |
|  - Spam Score 0.50 - 0.84: Route to INBOX with warning banner "[SUSPICIOUS PHISHING]".            |
|  - Spam Score < 0.50: Route directly to PRIMARY INBOX.                                            |
+---------------------------------------------------------------------------------------------------+
```

#### 2. Model Selection Rationale:
- **Multinomial Naïve Bayes:** Fast baseline inference; assumes conditional feature independence:
  $$P(\text{Spam} \mid \mathbf{x}) \propto P(\text{Spam}) \prod_{j=1}^D P(x_j \mid \text{Spam})$$
- **Linear SVM (Production Choice):** High-dimensional sparse text vectors ($D > 10,000$) are linearly separable with maximum margin, preventing false alarms (False Positives) on legitimate emails.
- **Evaluation Metric:** **Precision is prioritized over Recall** because routing an important university or work email to Spam (False Positive) is far more damaging than letting a minor promotional spam message through to the inbox (False Negative).
